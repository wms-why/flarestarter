### 新增

- **品牌可配置** — `APP_NAME`、`APP_URL`、`APP_GITHUB_URL`、`APP_LEGAL_NAME` 四个构建期变量（`src/lib/brand.ts`）驱动 UI 标题、SEO 标签、结构化数据、PayPal `brand_name`、邮件发件人显示名与 web manifest。只改 `APP_NAME` 就能全站改名。
- **`{app}` 插值** — `translate()` 把所有文案里的 `{app}` 全局解析成 `APP_NAME`，i18n 字典不再携带产品名，同步上游时也不再冲突。
- **部署命名参数化** — CI 用 `CF_WORKER_NAME` 设定 worker 名前缀；`db:*` 脚本通过 `scripts/db-name.mjs` 从 `wrangler.jsonc` 读真实 D1 库名，不再硬编码五份。

### 变更

- `common.appName` 与 `en.ts` / `zh.ts` 里的品牌文案改为 `'{app}'` 占位符。请设 `APP_NAME`，而不是改字典。
- `EMAIL_FROM` 留空时回落到 `<APP_NAME> <onboarding@resend.dev>`。
- web manifest 改由路由产出（`/manifest.webmanifest`），不再用 `public/manifest.json`，这样名称能跟随 `APP_NAME`。
- 仓库链接（页头、页脚、docs 导航、`git clone` 提示）在 `APP_GITHUB_URL` 为空时不渲染，不再产出 `href=""` 的死链。

### 说明

- `AGENTS.md` 末尾新增「本地约定」小节，下游只在自己的段落里追加，上游内容保持原样——fork 的规则请写进 `AGENTS.local.md`。
- 文档站（`src/content/docs/**`）仍然以模板名为主语：文档本来就要下游自己重写。
